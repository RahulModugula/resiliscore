The interface between backend and frontend. `parcel_score_schema.json` is canonical, and
`backend/app/models/schemas.py` and `frontend/src/types/resiliscore.ts` mirror it. Change all of them together.


`validation_report_schema.json` and `frontend/src/types/validation.ts` mirror the backend validation models.
`validation_report.json` is generated by `backend/scripts/build_validation_report.py` from the committed
flood, wildfire, and benchmark artifacts under `backend/validation/results/`. The frontend bundles this
report for offline inspection and validates live responses against the same schema.

The flood section includes observed per-depth bootstrap confidence intervals, event and basement-cohort
backtests, tract ranking, and the backend adoption decision. Benchmarks come from the pushed benchmark
lane, `38ad5d7`, and include their original measurements. Refresh with:

```sh
uv run --directory backend python scripts/build_validation_report.py
```
